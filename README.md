# Digital signal processing

Sampling, sample-and-hold, convolution and overlap-save exercises, followed by high-pass filter comparisons using Kaiser FIR and Chebyshev Type II IIR designs.

Install `requirements.txt`, then run the scripts in `HW1/` or `HW2/` to inspect their signal plots. Sampling frequencies, filter parameters and example signals are set in source.

These are numerical coursework experiments. Check SciPy compatibility for the imported window functions and keep frequency/normalization conventions consistent when comparing results.
